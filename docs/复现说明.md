# 公开基线复现与历史结果核对

本提交不含SATR-SSM代码、迁移适配层、兼容补丁及其训练/导出程序。可执行训练和重新推理限定为A/B/C/E四组RF-DETR基线；D/F保留实验记录和保存预测回放。

## 环境与基线训练

原始环境记录随各组results/experiments和logs保留。公开基线使用Python 3.11.17、PyTorch 2.4.1+cu121、torchvision 0.19.1、RTX 2080 Ti及FP32。

```bash
conda env create -f environment.yml
conda activate course-rfdetr-baseline
python -m pip install torch==2.4.1+cu121 torchvision==0.19.1+cu121 --index-url https://download.pytorch.org/whl/cu121
python -m pip install -r src/rfdetr_baseline/requirements.txt
python -m pip install -e src/rfdetr_baseline/vendor/rf_detr --no-deps
python scripts/download_assets.py --keys annotations,initialization,C
bash scripts/train.sh --group C --dataset /datasets/course/coco20_voc_5k --output /runs/C_reproduce
bash scripts/evaluate.sh --group C --dataset /datasets/course/coco20_voc_5k --output /runs/C_valid
```

数据恢复步骤见data/README.md和scripts/prepare_data.py。train/evaluate入口只接受A、B、C、E，训练参数从原resolved_config.json读取，仅重定位本机路径。D/F的原Python 3.12及其他真实训练设置作为历史实验信息保留。
